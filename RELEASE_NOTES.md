# e4steam Public Servers 0.1.0

- Draggable scrollbar and wheel support in the portable public-world catalog.
- Responsive full-window layout, dark background and correct rendering of wide buttons on old Forge releases.
- Fixed crashes when selecting the addon in Forge's Mods screen: logoFile now references a root-level PNG.
- Credits: Kamilchik and K2 Studio, with the Public Servers icon on every loader.
- Removed the temporary local status website and HTTP listener from every runtime JAR.
- Updated English/Russian README and community links; donations: https://dalink.to/kamilchik1231.

Seven loader artifacts cover Minecraft 1.17–26.3. The matching e4steam core with Addon API 1.1 is required. See README.md for the compatibility matrix and docs/TESTING.md for the exact scope of manual checks.
